# Urikem Legal — demo

UYAP verisiyle çalışan avukat asistanı Urikem Legal'in tanıtım sayfası. Bu sayfadaki bütün kişi, şirket, dosya numarası ve tutarlar uydurmadır; gerçek müvekkil verisi içermez.

Süre hesabı ve anonimleştirme, Av. Saadet Kartı'nın MIT lisanslı açık araçlarından alınmıştır (karti-sure.js, anonim.js; lisans notları dosyaların başında).
